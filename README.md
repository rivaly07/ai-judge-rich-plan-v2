Entry for make.fun bounty `ai-judge-rich-01`. The program writes one 984-character plan to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): a software agent with $100 and thirty
days sells a single $1,200 product, retrofitting live APIs with an x402 paywall and an MCP server
so autonomous agents can buy them per call, pitched by shipping a working paid endpoint on the
buyer's own repo before any invoice exists; buyers come from the official MCP registry and pay
USDC on Base on delivery, which keeps the whole money path free of invoices, KYC and banks, and
the arithmetic runs 500 contacts at 6% reply and one-in-four close to seven sales, $8,400 gross,
$8,440 held on day 30, with a named fallback of $149 template sales plus $250 retrofits on
Clustly and Claw Earn.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect, e.g.
`MAKEFUN_OUTPUT_DIR=/tmp/ajudge2-a python3 main.py`. Standard library only, no network, no
subprocess, identical bytes on every run.
